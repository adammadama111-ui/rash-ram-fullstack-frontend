## Выполненные проверки

- `node --check js/app.js`: синтаксис корректен.
- Модель DOM в Node.js: добавление, редактирование, удаление и отмена; валидация пустого названия и email; поиск без результатов; фильтр выполненных; сохранение задач/профиля; безопасный вывод строки с HTML; корректность календарных дат; пустое, повреждённое и недоступное хранилище.
- Статическая проверка HTML: локальные href/src существуют, уникальные id, формы имеют подписи, у img есть alt, нет style= и обработчиков onclick, на каждой странице есть обязательные семантические элементы.

Эти проверки не подтверждают визуальную раскладку и поведение реального браузера. Браузерная проверка и получение настоящих скриншотов в текущей среде недоступны.

## Ручной чек-лист перед сдачей

1. Открой каждую страницу при 1440, 900, 600, 390 и 320 px. Убедись, что нет горизонтальной прокрутки и наложений.
2. При 390 px проверь раскрытие меню и Escape. Пройди элементы клавишей Tab.
3. В модальном окне проверь Tab, Escape, закрытие кнопкой; после закрытия фокус должен вернуться в интерфейс.
4. Проверь добавление, изменение, отметку выполнения и удаление. Перезагрузи страницу и перейди на главную: данные и счётчики должны совпадать.
5. Проверь совместно поиск, предмет, статус и сортировку; для пустого результата должно быть сообщение.
6. Удали все задачи: примеры не должны возвращаться после перезагрузки, прогресс 0%.
7. Проверь формы с пробелами, пустыми данными, неверным email, длинным названием и отсутствующей датой.
8. Открой Console браузера: ошибок JavaScript быть не должно.
9. После GitHub Pages отдельно повтори переходы между страницами: относительные ссылки рассчитаны на размещение в подпапке репозитория.
