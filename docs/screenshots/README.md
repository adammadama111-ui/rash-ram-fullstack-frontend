# Настоящие скриншоты для README

Открой сайт через локальный HTTP-сервер или после публикации. Браузерные скриншоты в этой среде не получены, поэтому изображения-заглушки не приложены.

В Chrome или Edge нажми F12, затем Ctrl+Shift+M. Выбери Responsive и нужную ширину. Через меню DevTools (Ctrl+Shift+P) найди Capture full size screenshot и сохрани PNG:

| Файл | Страница | Ширина |
| --- | --- | --- |
| home-desktop.png | index.html | 1440 px |
| home-mobile.png | index.html | 390 px |
| tasks-desktop.png | tasks.html | 1440 px |
| profile-desktop.png | profile.html | 1440 px |

Положи файлы в эту папку, вставь соответствующие Markdown-изображения из раздела «Скриншоты» основного README и закоммить. Используй демонстрационный email, если не хочешь показывать личные данные. Главная на двух ширинах подтверждает требование одной страницы в двух вариантах.
