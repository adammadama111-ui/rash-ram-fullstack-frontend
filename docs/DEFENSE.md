# Как открыть и защитить StudyFlow

## 1. Быстрый запуск

Распакуй архив. Открой папку studyflow и дважды нажми START.bat. Если Python установлен, появится окно сервера. Открой браузер по адресу http://localhost:8000. Окно сервера не закрывай, пока показываешь проект. Для остановки нажми Ctrl+C. VS Code можно использовать для просмотра и изменения файлов; проект не нужно запускать как Python-программу — это сайт, Python здесь только отдаёт файлы браузеру.

## 2. Идея и аудитория

Проблема: студент получает задания по нескольким предметам и может забыть срок или потерять список. Решение: единый планировщик с задачами, датами, приоритетами и статистикой. Аудитория: студенты колледжа или вуза. Главный сценарий: открыть задачи, добавить задание, выбрать срок и предмет, сохранить, затем отметить выполнение и увидеть обновление прогресса.

## 3. Пример выступления на 2–3 минуты

«Мой проект называется StudyFlow. Это планировщик учебных задач для студентов. Здесь три страницы: обзор, мои задачи и профиль. На главной видны общее количество заданий, задания в работе, выполненные и просроченные. Ближайшие дедлайны выводятся автоматически.

Сайт написан на HTML, CSS и JavaScript без фреймворков. HTML отвечает за структуру страницы, CSS — за оформление и адаптивность, JavaScript — за поведение. На всех страницах общие стили и навигация.

На странице задач можно добавить задание, отредактировать его, найти по названию, отфильтровать по предмету или состоянию, изменить сортировку. Форма проверяет название и дату. Удаление требует подтверждения. Отметка выполнения обновляет статистику.

Данные хранятся в localStorage, поэтому не пропадают после перезагрузки. Сервер и база данных по заданию не нужны. Профиль учебный, без реальной регистрации.

На мобильной ширине страницы перестраиваются с помощью media queries, Flexbox и Grid. Меню становится раскрываемым. Также есть подписи полей, alt изображения, видимый фокус и доступные названия кнопок».

Про GitHub и публикацию говори только после их фактического выполнения; не заявляй, что репозиторий создан, пока его нет.

## 4. Что показывать преподавателю

1. Открой главную и объясни показатели. «В работе» включает все невыполненные задачи, в том числе просроченные; это не взаимоисключающие категории.
2. Перейди в «Мои задачи», нажми «Новая задача». Попробуй пустое название: появится ошибка. Затем добавь настоящее задание.
3. Найди добавленное задание через поиск, выбери предмет и состояние. Покажи сортировку.
4. Отредактируй срок или название. Отметь выполнение и перейди на главную: статистика обновится.
5. Перезагрузи страницу: данные сохранятся. Покажи отмену удаления, затем подтверждение.
6. В профиле введи неверный email, затем корректный. Сохрани имя и вернись на главную: приветствие изменится.
7. Открой F12, включи мобильный режим и покажи главную при ширине 390 px и меню.
8. Открой исходные файлы и, после публикации, историю коммитов в GitHub.

## 5. Как устроен код

**index.html / tasks.html / profile.html.** В head подключаются общий CSS и JS с defer. defer позволяет выполнить скрипт после разбора HTML. header содержит nav, основной контент находится в main, страницы разбиты на section. Формы имеют label. dialog — нативное модальное окно: браузер ограничивает фокус внутри и поддерживает Escape.

**css/styles.css.** В :root находятся переменные палитры. Повторяющиеся классы button, panel и task-card задают единый дизайн. Grid распределяет карточки по колонкам, Flexbox выравнивает элементы в строках. Media queries при 900 и 600 px меняют количество колонок и вид меню. sr-only скрывает текст визуально, но оставляет его для вспомогательных технологий.

**js/app.js.** tasks — массив объектов. У каждой задачи есть id, title, subject, date, priority, done. Profile — отдельный объект name/email/group. localDate() формирует локальную дату, не сдвигая её в UTC. isOverdue() сравнивает строковые даты в формате YYYY-MM-DD; выполненная задача не считается просроченной.

readStorage() читает JSON и проверяет структуру; writeStorage() сериализует массив через JSON.stringify(). Обе функции обрабатывают ошибки. localStorage хранит строки, поэтому нужен JSON.parse() при чтении. Это не база данных и не общее хранилище разных устройств.

taskCard() создаёт DOM-элементы. Пользовательский текст передаётся через textContent, поэтому строка с HTML отображается как текст. renderTasks() последовательно применяет поиск и фильтры через filter(), затем сортирует найденные задачи. renderStats() вычисляет количество выполненных и процент. При пустом массиве процент равен 0: деления на ноль нет.

addEventListener() связывает действия с кодом. При submit вызывается preventDefault(), чтобы браузер не перезагружал страницу. Если форма корректна, объект добавляется через push() или обновляется через Object.assign(). При удалении splice() убирает найденный элемент. persistTasks() сохраняет данные и перерисовывает интерфейс.

## 6. Ответы на возможные вопросы

| Вопрос | Ответ |
| --- | --- |
| Почему три HTML-файла? | У каждой страницы своя задача, навигация связывает их, CSS и JS общие. |
| Чем отличается id от класса? | id обозначает конкретный элемент, класс объединяет элементы с общими стилями. |
| Зачем required, если проверка в JS? | Атрибут описывает обязательность поля, а JS даёт понятные сообщения и проверяет пробелы. novalidate отключает стандартные всплывающие ошибки. |
| Почему не React? | По требованиям используется чистый JavaScript; фреймворк здесь не нужен. |
| Почему email не выполняет вход? | Профиль — демонстрационный frontend-сценарий; настоящая авторизация требует backend. |
| Что происходит при очистке браузера? | localStorage удаляется, при следующем запуске появятся примеры. |
| Можно ли открыть на другом устройстве? | Да, если сайт опубликован, но сохранённые задачи будут другими. |
| Для чего Git? | Он сохраняет этапы изменений, позволяет видеть историю и откатывать код. |

## 7. Простые изменения на защите

- Цвет кнопок: измени --accent и --accent-dark в :root.
- Текст заголовка: измени h1 в нужном HTML-файле.
- Число ближайших задач: измени slice(0, 3) в renderUpcoming().
- Мобильная граница: найди @media (max-width: 600px) в CSS.
- Минимум символов названия: меняй согласованно minlength в HTML, проверку submit и isTask в JS.
- Новый предмет: добавь его в subjects в JS и в оба select на tasks.html.

Перед защитой обязательно сама пройди сценарий и прочитай функции. Знание текста выступления не заменяет понимание кода.
